PROBLEM DESCRIPTION: My project is a comprehensive school management system. It
enables school administrators to efficiently manage various aspects of their institution, such as
student enrollment, and scheduling. The system provides a user-friendly CLI (command-line) interface 
that enables easy navigation and interaction. The program uses various data structures and algorithms to optimize its performance.The ultimate goal of this project is to create an efficient and reliable tool that simplifies the day-to-
day tasks of school administration, making it easier to provide quality education to students.

PROGRAM DOCUMENTATION: The way to run the program is very simple and easy to follow. When running if no parameter are entered
then it will ask you for the file with all the student data. That file should include first name, last name, current year, and expected graduation year. Once the file has been entered 3 different distinct options will appear, and those options include exiting the program, viewing teacher information which shows all the classes
teachers are assigned to, and student information. Within student information you'll be able to add and view classes of that student. When trying to add classes it will prompt you for a file containing all the available classes which should include the subject and course code. Their are many areas that I would have like to improved on if even the time. I would have liked to made and abstract user class that both teachers and students can extend from. I also would have liked to implement a way in which teachers could edit some student information. Finally, creating an admin class that edit both teachers and students would be cool too.

LIST DATA STRUCTURE: I chose to user vectors in a bunch of different things in my program such as storing classes and student data. I believe vectors are super easy to work with and I just needed some sort of dynamic array that could be templated and I wouldn't have to create it myself. It implemented well when I was getting the student data and class data, I also was able to use vectors on the student that stored a list of classes that they were enrolled in.
