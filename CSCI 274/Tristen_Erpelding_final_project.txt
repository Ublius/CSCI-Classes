2. ArchLinux and Ubuntu are very different when it comes to Linux distros. I have often heard of Arch being told as if "you shot your foot, liked it, so you decide to shoot your other foot." I feel as if this is an extreme analogy because with Arch you have full control over the environment and it's very raw and fresh. Arch uses the Pacman package manager which is a rolling release model updating packages as soon as they are available. Pacman requires users to manually resolve dependencies and configure packages. Ubuntu on the other hand uses the Advanced Package Tool which is known as "apt", this package manager handles package dependencies automatically making installation/removal very easy to do. Ubuntu works on a Long Term Support release where only the most stable releases are used. When comparing desktop environments Arch allows for full customization on installation giving users the option to choose which environment they want to use, with the most common one being XFCE as it is usually the most lightweight environment out there. Ubuntu on the other hand uses GNOME by default, Ubuntu still allows for other environments to be used however the integration is not as friendly as Arch. During the installation on Arch, it allows users to choose which shell they would like to use however on Ubuntu it defaults to Bash. On both distros, it is very easy to switch between different shells. Arch uses a rolling release schedule giving users continuous updates, while Ubuntu uses the LTS release schedule with releases every two years. Arch is very good for high levels of customization and making it what you want it to be however it has a very steep learning curve for new users making it difficult. Ubuntu on the other hand is very user-friendly and comes pre-installed with many tools, software, and packages making it a great choice for new users wanting a Linux distro to "just work", however, it lacks many of the customization that Arch provides. Ubuntu requires much more work to make it your own.

3. A tiling window manager organizes open windows in a non-overlapping way. Tilling windows automatically are positioned to fit the screen without needing to be manually reszied. This differs from a regular window manager because those windows can overlap each other and be behind one another. A common tiling window manager is known as i3 it is used for its simplicity and efficiency as well as being easily configurable. Parrot OS does not use a tiling window manager it uses the typical floating window manager.

6. A journaling file system is used for the reliability and recovery of the file system because it creates a log of the changes it is going to perform. It stores the inode information before the change in a "journal". Once the information is logged for change it updates the changed information to the disk. It will periodically update the journal with what's on the disk to ensure they are in the same state. This can be used in the event of a crash to be able to roll back and use the journal for recovery. Ext2 is a file system that is not a journaling file system, it is one of the predecessors to ext4. Ext2 is still commonly used because of the lack of a journaling system it makes it a great choice for flash-based storage media because it is more perfomant as it has less number writes as there is no journaling it needs to perform.
